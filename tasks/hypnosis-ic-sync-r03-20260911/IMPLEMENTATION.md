The smallest implemented controller is benchmarked against the old failure cases, not praised merely for having more rules.

The code consumes structured evidence-linked reports and events; it does not diagnose from text or read a body. The versioned `hypnosis-session-map-v2` contract intentionally rejects accidental use by the legacy `guide-graph-v1` priority selector. Its explicit adapter is `src/hypnosis-guide/context.mjs`. This is an executable **development candidate**, not a change to the deployed app or voice frontend.
