# Public guide derivative contract

The public reader-facing Inner Signal guide is a one-way derivative of the canonical guide/source authority and executable graph authority. It is not a second therapy authority.

Humanization may freely change voice, compression, examples, section order, pacing, memoir, humor, transitions, citations, and layout. It may combine several upstream concepts into one natural passage and omit implementation-only mechanics. It may not silently create, remove, reverse, broaden, narrow, or weaken therapy semantics.

A public-only wording change never changes runtime behavior. A genuinely new therapeutic distinction, intervention, safety or consent rule, routing rule, authority claim, or conceptual correction discovered during humanization must go back through the normal source/graph/owner-approval process before it can affect canonical behavior.

When upstream semantics change, repair only the affected public passages. Do not re-humanize the whole article for unrelated upstream changes. Fidelity is defined by preserved meaning, not wording similarity or one-public-paragraph-per-node coverage.

When an exact public derivative artifact is first registered, create a non-authoritative semantic sync manifest that records:

- stable concept/obligation ID;
- canonical source anchor(s), source hash(es), or owner-amendment IDs;
- related graph node(s) or route(s) when applicable;
- the meaning that must survive humanization;
- public heading/anchor or passage identifier;
- public artifact/version/hash;
- status: `SYNCED`, `DRIFTED`, `NOT_PUBLIC`, or `PROPOSED_UPSTREAM`;
- notes for intentional compression, relocation, or omission.

`NOT_PUBLIC` is valid for implementation-only mechanics. `DRIFTED` blocks publication of the affected semantic claim. `PROPOSED_UPSTREAM` means the public edit introduced substantive new meaning that has not yet become canonical.

Before publishing a humanized version, bind the exact upstream authority used for the pass, identify changed passages carrying therapy semantics, classify each as style-only, semantic-preserving rewrite, intentional omission/relocation, or proposed upstream semantic change, verify that no change silently alters safety, consent, boundaries, accountability, uncertainty, authority, sequencing, or efficacy claims, and retain the exact public artifact/version/hash as provenance.

There is no background bidirectional sync. Publication does not imply owner approval, runtime authority, installation, stable promotion, clinical validation, or model adherence.
