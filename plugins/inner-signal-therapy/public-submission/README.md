# Inner Signal Therapy public-submission preparation

This directory is a private, reviewable preparation packet for a possible future OpenAI
public plugin submission. It is not an OpenAI Platform submission draft, approval, or
publication record.

The packaged plugin remains skills-only. It contains static instructions and a frozen
advisory map. It has no MCP server, app integration, hook, authentication layer, external
endpoint, telemetry, publisher-controlled database, or durable plugin-side storage.

The internal package artifacts are complete enough for deterministic review. Public release
is still blocked on verified publisher identity, public website and support pages, published
privacy and terms URLs, production brand assets, and an explicit availability decision.
None of those external facts is fabricated here.

The static plugin does not persist potential lessons or write to the private InnerSignal
browser candidate store. Persistent learning would require a separately authorized,
tool-backed runtime; no such runtime is included or authorized by this packet.

Use `tasks/inner-signal-plugin-public-prep-20260831/verify-plugin-public-prep.mjs` to validate
the package and its fail-closed readiness state.
