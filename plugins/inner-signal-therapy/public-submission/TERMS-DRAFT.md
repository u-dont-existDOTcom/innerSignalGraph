## Prepared package scope

Inner Signal Therapy is a skills-only advisory package for reflective inner-child and
self-relationship responses. It provides static instructions and a frozen advisory map to
the host model. It does not provide an MCP server, account service, storage, telemetry,
diagnosis, prescribing, emergency response, or guaranteed therapeutic outcome.

The package should preserve uncertainty, respond to the person's stated situation, and
offer a proportionate next move. It is not a substitute for emergency services, clinical
diagnosis, or individualized professional care.

jurisdiction, dispute terms, age eligibility, payment terms, or a binding agreement. Those
