# Privacy policy draft — not published

This is a private preparation draft. It has not been published, approved as legal advice,
or authorized for use as a public policy URL.

## Package scope

Inner Signal Therapy is prepared here as a skills-only plugin. The package contains static
instructions and a frozen advisory reference. It includes no MCP server, external API
endpoint, authentication layer, publisher-controlled database, telemetry, or durable
plugin storage.

The static package does not persist potential lessons. It does not give the publisher
access to a user's conversation through a plugin-controlled service because this package
contains no such service. It does not write to the separate private InnerSignal browser
candidate store.

The host platform handles conversations and other platform data under the host platform's
applicable policies and user controls. This draft makes no claim about platform retention,
training, or processing beyond those current official policies.

Persistent InnerSignal correction learning is a separate local-runtime capability and is
not part of this public skills-only package. Adding any server, authentication, storage,
telemetry, or other publisher-controlled data flow would require a new privacy review and
an updated public policy before release.

No regulatory certification or compliance status is claimed by this draft.
