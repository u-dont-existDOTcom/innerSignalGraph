# Release notes draft

Private preparation draft for an initial skills-only submission. No submission exists yet.

Inner Signal Therapy packages a single static skill and its frozen advisory map for
inner-child and self-relationship responses. The package instructs the host model to
understand the particular person, preserve uncertainty and safety constraints, give a
useful next move, and avoid mechanically reciting the map.

This preparation cycle adds public-listing drafts, synthetic starter prompts, five positive
and three negative reviewer cases, readiness evidence, and deterministic package
validation. It does not modify the Skill or map, add MCP, connect to a runtime, or create
storage. No test credentials or account setup are required for the synthetic cases.

Owner and legal review, verified publisher identity, public policy/support URLs, production
branding, availability selection, OpenAI submission, review, and publication remain future
steps.
